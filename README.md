# 坦克大战 · Battle City

一个纯 HTML + Canvas + JavaScript 实现的经典《坦克大战》（Battle City）游戏，**零依赖**、单文件，直接用浏览器打开即可游玩。

![版本](https://img.shields.io/badge/version-1.0-blue) ![语言](https://img.shields.io/badge/HTML5-Canvas-orange) ![许可证](https://img.shields.io/badge/license-MIT-green)

## ✨ 特性

- 🎮 经典坦克大战玩法：保卫基地、消灭敌人、逐关推进
- 🧱 四种地形：可破坏的砖墙、不可破坏的钢墙、阻挡坦克的河流、隐藏坦克的树林
- 🤖 四种敌人：普通、快速、强力（2 血）、重甲（3 血），带有随机移动与射击 AI
- 🎁 道具系统：消灭**闪烁**的敌人可掉落道具
  - 🛡 护盾（短暂无敌）
  - ❤ 生命（+1 条命）
  - ⭐ 火力（提升子弹速度与弹数上限）
  - 💣 炸弹（消灭全屏敌人）
- 🔊 使用 Web Audio 合成的简单音效，无需任何外部资源
- 🕹 无限关卡，难度随关卡递增
- 📱 像素风格渲染，经典复刻

## 🎮 操作

| 按键 | 功能 |
|------|------|
| 方向键 / `W` `A` `S` `D` | 移动坦克 |
| 空格 / `J` | 发射子弹 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 进入下一关 |

## 🚀 如何运行

**方法一：直接打开（最简单）**

下载仓库后，双击 `index.html` 用浏览器打开即可。

**方法二：本地服务器**

```bash
# 在仓库目录下执行（任选其一）
python -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000`。

**方法三：在线游玩（GitHub Pages）**

1. 打开仓库的 **Settings → Pages**
2. 将 **Source** 设为 `main` 分支的根目录 `/ (root)`
3. 保存后即可通过 `https://<你的用户名>.github.io/<仓库名>/` 在线游玩

## 🛠 实现说明

- 地图：13×13 单元网格（每个单元 2×2 瓦片，共 26×26 瓦片），左右镜像对称，自动展开
- 移动：逐像素平滑移动，碰撞检测基于坦克包围盒与瓦片网格的相交判定，支持沿墙滑动
- 子弹：矩形碰撞检测，命中砖墙销毁单个瓦片、命中钢墙被阻挡、可越过河流
- 敌人 AI：随机转向 + 一定概率瞄准玩家，随机射击
